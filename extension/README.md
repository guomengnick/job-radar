# 送到雷達（Chrome 擴充功能）

按一下工具列上的「送到雷達」圖示，會跳出一個小視窗，裡面有三個功能（第四個功能「帶入應徵」從 Telegram 的連結開始，見下面）：

**送出這一頁評分**：目前這一頁的文字送到 job-radar 的 clip 函式，由 Claude 依你的評分檔案評分，結果用 Telegram 回覆。

- 圖示上的徽章：`…` 評分中，數字是分數（綠 75 以上、黃 55–74、紅 55 以下），`✗` 是失敗（原因看 Telegram 或 CloudWatch 的 `/aws/lambda/job-radar-clip`）。
- 只有在你按下按鈕時，才會讀取目前這一頁（`activeTab` 權限），不會自己去讀任何網頁。
- 頁面是你自己用瀏覽器正常打開的，擴充功能只讀你畫面上已經顯示的文字。

**批次送到雷達**：所有開著的 104 職缺頁一次送出，由 Claude 用批次 API 評分（半價），總表通常一小時內用 Telegram 傳來。

- 送出後馬上會收到「收到幾頁、送 AI 幾頁、規則排除幾頁、略過幾頁」，分頁就可以關了。
- 規則排除：職稱、地點或薪資符合 SSM 參數 `/job-radar/batch-rules` 的不送 AI，但總表會列出來給你抽查。怎麼改見 `docs/DEPLOY.zh-TW.md`。
- 略過：兩週內評過的同一個職缺，或還沒載完、被 Chrome 暫停的分頁（總表上會寫原因，重新整理後再送一次即可）。
- 這個功能要讀「不在最前面」的分頁，所以需要兩個權限：讀分頁網址（`tabs`），和讀 `www.104.com.tw` 的頁面。重新載入時 Chrome 會問你。只有按下按鈕時才讀，而且只讀 104 職缺頁。

**開啟 104 配對信的職缺**：列出從某一天起，104 配對信裡第一次出現的職缺，分成三組，每組都可以勾選要不要開：

| 組別 | 是什麼 |
|---|---|
| 日報有列的（遠端、台中） | Telegram 日報列出的那些 |
| 台中以外、非遠端 | 104 自己推薦、不在你搜尋條件裡的 |
| 被規則排除的（職稱、薪資） | 職稱含排除詞（`config/radar.yml` 的 `title_exclude`）或薪資低於門檻 |

- 按「開啟」後，會開一個新視窗，每 1.5 秒開一個分頁（50 個大約 75 秒），圖示上的數字是還剩幾個。開到一半可以直接關掉那個視窗。
- 分頁只在你按下按鈕時才開，不會在背景自己開，所以跟你自己一個一個點開一樣，104 看到的是你本人的瀏覽器。
- 日期預設今天，最多往回 13 天。

## 帶入應徵（從 Telegram 連結）

Telegram 上 **70 分以上的 104 職缺**，最後一行有兩個連結：

- **看職缺**：只打開職缺頁。
- **帶入應徵**：打開職缺頁和 104 的應徵視窗（104 自己的 `?apply=form`），擴充功能接著
  1. 在「選擇履歷」選好 AI 判斷的版本（A、A+ML、B、B+ML、C、C+ML）對應的履歷；
  2. 推薦信寫成「開頭、AI 依這個職缺寫的一句、結尾」；
  3. 在頁面左上角說明做了什麼、哪裡要你手動補。

**它不會按「確認送出」**，也不會勾「儲存此次修改」「新增自我推薦信」，所以你在 104 存的推薦信範本不會被改。看過再自己送出。

- 版本和那一句放在網址 `#` 後面（`#radar-apply?cv=…&line=…`）。`#` 後面的部分瀏覽器不會傳給 104 的伺服器；擴充功能讀完就把它從網址拿掉。
- 只有網址帶著 `#radar-apply` 時才會動作，平常打開 104 職缺頁什麼都不做。
- 第一次用之前，到設定頁的「一鍵帶入應徵」填好：每個版本對應的 104 履歷名稱（要跟 104 下拉選單裡的一字不差），和推薦信的開頭、結尾。這些只存在這台電腦的 Chrome 裡，不會進 git（這個 repo 是公開的）。
- 在手機上點連結，一樣會打開應徵視窗，只是手機沒有擴充功能，履歷和推薦信要自己選。

## 安裝（每台電腦一次）

1. 在 repo 根目錄執行下面這行。它從 AWS 讀出接收網址和密鑰，寫進 `extension/config.local.js`（不會進 git），密鑰不會顯示在畫面上：

```bash
AWS_PROFILE=radar make extension-config
```

2. Chrome 開 `chrome://extensions`（Edge 是 `edge://extensions`），打開右上角的「開發人員模式」。
3. 按「載入未封裝項目」，選這個 `extension` 資料夾。已經載入過的話，按擴充功能卡片上的重新載入圖示（改版後都要按一次，新的小視窗才會出現）。
4. 把「送到雷達」釘選到工具列（拼圖圖示 → 圖釘）。

設定頁會自動填好，不用打開。

### 另一台電腦（例如 Windows）

把跑過 `make extension-config` 的整個 `extension` 資料夾複製過去（隨身碟、雲端硬碟都可以），再照上面第 2～4 步載入。這個資料夾裡有密鑰，不要公開分享。

沒有那個檔案的話，也可以在設定頁手動貼上兩個值：接收網址是 `terraform -chdir=infra output -raw clip_url`，密鑰是 SSM 的 `/job-radar/clip-secret`。

## 換密鑰

密鑰外洩時，產生新的、覆蓋舊的，再重新執行 `make extension-config` 並重新載入擴充功能（手動填過設定頁的話，要在設定頁換成新值）：

```bash
aws ssm put-parameter --profile radar --region ap-southeast-2 --name /job-radar/clip-secret --type SecureString --overwrite --value "$(openssl rand -hex 32)"
```

## 費用

單頁評分是一次 Claude 呼叫；批次是半價的 Message Batch，總表最後一行會寫這批用了多少 token、約多少美元。模型和思考強度在 `config/radar.yml` 的 `assess`。花費上限請設在 Anthropic Console 的 Limits。
